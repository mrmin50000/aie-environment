# Отчёт по итоговому проекту

## 1. Паспорт проекта

- **Название проекта:** Классификация дефектов поверхности стали
- **Автор:** `Салтыков Данила Михайлович`
- **Группа:** `ИКБО-50-24`
- **Контакт:** `@grgesf1`

Проект посвящён построению сервиса классификации дефектов поверхности стали по изображению. Используется открытый датасет NEU Surface Defect Database. Реализованы transfer learning с ResNet18 и MobileNetV2. Результат — REST API (FastAPI), принимающий изображение и возвращающий класс дефекта и вероятности по классам.

---

## 2. Постановка задачи

**Предметная область:** Контроль качества металлургической продукции. Определение типа дефекта на поверхности стали позволяет автоматизировать инспекцию и снизить долю брака.

**Задача в терминах ML:** Многоклассовая классификация изображений (6 классов).

- Вход: изображение 200×200, grayscale
- Выход: класс дефекта + вероятности для всех классов
- Ограничения: скорость инференса < 1 с на CPU, возможность развёртывания без GPU

**Целевые метрики:**
- Accuracy — общая доля верных ответов
- F1-score (macro) — среднее F1 по классам (основная метрика)
- Confusion Matrix — анализ ошибок между классами

## 3. Данные

### 3.1. Источник

NEU Surface Defect Database (NEU-DET) — открытый датасет, содержащий изображения поверхности горячекатаной стали с шестью типами дефектов.

- **Ссылка:** https://www.kaggle.com/datasets/kaustubhdikshit/neu-surface-defect-database

### 3.2. Структура

| Характеристика | Значение |
|----------------|----------|
| Всего изображений | 1800 |
| Размер | 200×200 px |
| Цветность | Grayscale (1 канал) |
| Формат | JPEG |
| Классы | 6 (сбалансированы, по 300 шт.) |
| Разметка | Bounding boxes в Pascal VOC XML |

### 3.3. Предобработка

- Конвертация grayscale → RGB (повторение канала 3 раза) для совместимости с ImageNet-претренированными моделями
- Ресайз до 224×224 (crop/resize)
- Нормализация: mean=0.5, std=0.5 по каждому каналу

### 3.4. EDA

Ключевые наблюдения (подробнее — `notebooks/01_eda.ipynb`):

- Классы сбалансированы: 240 train + 60 val на каждый класс
- Каждое изображение содержит 1+ bounding box'ов
- Размеры дефектов варьируются от мелких (10×10 px) до крупных (150×150 px)

## 4. Модели и подходы

### 4.1. Baseline: Simple CNN

Свёрточная сеть с 4 слоями (32→64→128→256 фильтров) + классификатор (256→128→6).  
Обучение с нуля, без предобученных весов.

### 4.2. Transfer Learning: ResNet18

Предобученная на ImageNet ResNet18. Замена последнего fully-connected слоя на 6 классов.  
Стратегия: AdamW (lr=1e-3), ReduceLROnPlateau, early stopping.

### 4.3. Transfer Learning: MobileNetV2

Предобученный MobileNetV2 (torchvision). Лёгкая архитектура (3.5M параметров), подходит для ограниченной памяти. Аналогичная стратегия обучения.

---

## 5. Результаты

### 5.1. Сравнение моделей

| Модель | Val Accuracy | Параметры | Время инференса (CPU) |
|--------|-------------|-----------|----------------------|
| SimpleCNN (baseline) | 0.9583 | G1.2M | < 10 ms |
| ResNet18 | 0.923 | 11.2M | ~ 30 ms |
| MobileNetV2 | 1.0 | 3.5M | ~ 25 ms |

### 5.2. Выбор финальной модели

Финальная модель — **MobileNet2**, как оптимальный баланс точности, скорости и простоты развёртывания. При необходимости может быть заменена на ResNet18 через конфиг.

### 5.3. Эксперименты

- Learning rate: 1e-3 оптимален, 1e-4 сходится медленнее, 3e-3 нестабилен
- Аугментации: RandomCrop + HorizontalFlip + Rotation(10°) + ColorJitter дают +3-5% к accuracy
- Freeze backbone: заморозка на первых 5 эпохах, потом fine-tune — даёт лучшую сходимость

## 6. Архитектура решения

### 6.1. Пайплайн

```
Изображение → [FastAPI] → [Preprocess] → [Model] → [Softmax] → JSON
```

- `/predict` принимает файл через multipart/form-data
- Предобработка: resize 224×224, нормализация
- Модель: загруженная из `artifacts/best_model.pth`
- Ответ: класс + вероятности по всем классам

### 6.2. API

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| `/health` | GET | Статус сервиса |
| `/predict` | POST | Классификация изображения |

### 6.3. Технологический стек

- PyTorch / torchvision — модели
- FastAPI + uvicorn — сервис
- TensorBoard — логирование экспериментов
- pytest — тестирование

## 8. Ограничения

- Модель обучена на синтетических/лабораторных данных — на реальных фотографиях с производства может работать хуже
- Классификация всей картинки целиком, а не детекция отдельных дефектов
- Размер обучающей выборки небольшой (1440 изображений)

### Дальнейшая работа

- Добавить детекцию (YOLO / Faster R-CNN) для локализации дефектов
- Увеличить выборку через дополнительные аугментации и синтетические данные
- A/B-тестирование на реальных данных с производства
- CI/CD + Docker для автоматического развёртывания
